# Monitoo Help Desk

Crie um sistema web de chamados internos de TI para a empresa "Monitoo". Existem dois perfis: Colaborador, que abre chamados (título, descrição, prioridade) e acompanha os seus, e Técnico, que vê todos os chamados, assume um chamado, altera o status (Aberto, Em atendimento, Resolvido) e comenta. O colaborador não pode ver chamados de outras pessoas. Inclua um painel com chamados por status.
